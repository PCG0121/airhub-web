# AirHub 3D Website

Deploy-ready static website for AirHub. It runs directly on GitHub Pages with no
build command.

## Included

- Procedural Three.js aircraft, globe and particles
- GSAP ScrollTrigger transitions
- Lenis smooth scrolling on desktop
- Responsive mobile layout and reduced-motion fallback
- Local browser libraries in `vendor/`
- Existing destinations, search, deals and about sections

## Publish on GitHub Pages

Upload the contents of this folder to the root of the `main` branch in
`PCG0121/airhub-web`. Keep the directory names unchanged. GitHub Pages will
publish the update automatically after the commit is processed.
